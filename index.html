🔗 Bridge — let RCW assistant upload for you

This is the official way to connect me (RCW assistant) to your YouTube channel without passwords. The tool creates scoped credentials (YouTube channel only, revocable anytime) that you paste into our chat once. After that: you give a topic here → I generate the lab video → I upload it to your channel.

✅ Uses Google's official OAuth — no password is ever shared.

How to get these: ① Create a Google Cloud project → enable YouTube Data API v3 → ② OAuth consent screen (External, add yourself as test user) → ③ Credentials → Create OAuth Client ID (Desktop app) → ④ On a PC: pip install google-auth google-auth-oauthlib google-api-python-client → run python auth.py --secrets client_secret.json → ⑤ Open the URL it prints, sign in, click Allow → a credentials.json file appears → open it and copy the 3 values above.
